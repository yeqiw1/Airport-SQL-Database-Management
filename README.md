# Airport SQL Database Management System

A Python-based airport database management project that uses SQL to store, retrieve, and manage airport-related data. The project demonstrates relational database concepts, SQL query execution, and Python database integration.

## Features

- **Airport Data Management:** Organizes and manages airport-related information using a relational database.
- **SQL Queries:** Retrieves and processes data using SQL statements.
- **Python Integration:** Connects Python scripts to a SQL database for data access and processing.
- **Data Retrieval:** Extracts relevant information from the database based on specified queries.
- **Relational Database Design:** Uses structured tables and relationships to organize information efficiently.

## Technologies Used

- **Programming Language:** Python
- **Query Language:** SQL
- **Database:** Relational Database
- **Core Concepts:** Database Management, SQL Queries, Data Processing

## How It Works

1. **Database Connection:** The Python application connects to the airport database.
2. **SQL Query Execution:** Executes SQL statements to retrieve and manage airport-related records.
3. **Data Processing:** Python processes the results returned by the database.
4. **Result Output:** Retrieved information is displayed through program output.

## Getting Started

### Prerequisites

- Python 3
- Required SQL database and Python database connector
- Airport database files, if applicable

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-directory>
   ```

3. Configure the database connection and initialize the database if required.

4. Run the application:

   ```bash
   python project2.py
   ```
